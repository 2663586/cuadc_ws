
## 投放区任务流程

### 方案选择：两级检测 + 视觉伺服对准

经分析，推荐采用 **粗检测 + 精对准** 的两级方案：

### 阶段一：粗检测（安全高度 ~7m）

在安全高度（起飞后巡航高度 7m），投放区 3 个圆筒全部在视野内。此时通过下视/前向摄像头的图像：

1. **YOLO 检测圆筒**：定位所有 3 个白色圆筒在图像中的边界框
2. **计算圆筒坐标**：利用针孔相机模型（详见[[针孔相机模型与图像中物体大小计算]]），通过圆筒在图像中的像素大小和已知高度，反算每个圆筒的 NED 坐标
3. **判定优先级**：
   - 估算各圆筒直径 → 判定编号（15cm / 20cm / 25cm）
   - 优先选择 1 号筒（15cm = 500 分），如不可行则选 2 号筒（20cm = 300 分）
4. **选择目标并下达投放策略**：输出两个目标圆筒的 NED 坐标

> 在 7m 高度使用普通广角摄像头，15cm 宽圆筒在图像中像素占比少，直径估算误差可能较大。建议在此阶段仅做**粗分类**（大/中/小），降到低空后再精确确认。==问题在于在这个高度（可以看到整个投放区的高度），怎么去区分这个大小。方案可以有：使用针孔相机模型（或PnP）计算；直接比较检测框大小。==

### 阶段二：精对准（低空 2-3m）

飞行器下降到目标圆筒上方 2-3m：

1. **YOLO 重新检测** + **HoughCircles 精确定位圆筒中心**
2. **单目位置解算**（PnP + 已知圆筒尺寸）→ 获得圆筒相对飞行器的精确 3D 偏移
3. **视觉伺服 PID**：
   - 输入：圆筒中心与图像中心的像素偏差 → 换算为 NED 位置偏差
   - 输出：offboard `set_velocity_ned` 或 `set_position_ned`，控制飞行器移动到圆筒正上方
   - 当像素偏差小于阈值 → 判定为”已对准”
4. **投放**：
   - 对准后发送 `action.set_actuator(index, 1.0)` 释放舵机
   - 记录投放时刻位置到日志
5. **水面下落轨迹**：从 2-3m 高度释放，考虑水平风的影响。可在低空投放阶段微调悬停位置补偿风偏。

注意事项：
- 超时保护
- 蓝色区域

### 阶段三：投放第二个水瓶

1. 第一个水瓶投放后，飞行器上升回 3-4m
2. 平移至第二个目标圆筒上方
3. 重复阶段二流程

关于**计算**，详见[[针孔相机模型与图像中物体大小计算]]
