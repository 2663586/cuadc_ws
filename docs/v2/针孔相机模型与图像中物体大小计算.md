## 针孔相机模型
### 基本原理
**针孔相机模型**是一种简化的光学成像模型，基本原理是**中心透视投影**，将三维空间中的物体通过针孔投影到二维成像平面上。这种模型忽略了镜头畸变、光线衍射等复杂因素，使得计算和分析变得相对简单，因此也广泛应用于计算机视觉和图形学领域。
### 坐标系转换
#### 四个坐标系
1. 世界坐标系：描述客观世界绝对位置$(X_W, Y_W, Z_W)$
2. 相机坐标系：以相机光心为参考点建立的三维坐标系，其为原点，相机主光轴为Z轴，平行于图像平面水平方向为X轴$(X_C, Y_C, Z_C)$
3. 图像坐标系：定义在成像平面上的二维坐标系，相机主光轴和图像平面的交点为原点（像主点）$(x, y)$
4. 像素坐标系：描述相机图像，即像素在图像平面中的位置索引，图像平面左上角为原点，u轴平行于图像坐标系的X轴，水平向右，v轴平行于图像坐标系的Y轴，垂直向下$(u, v)$
#### 坐标变换
**世界坐标系 -> 相机坐标系**：
世界坐标系需要经过旋转和平移转换成相机坐标系。$R$是旋转矩阵，一般是$3\times3$矩阵；$t$为平移向量，一般为$3\times1$矩阵。
$$
\begin{bmatrix}X_C\\Y_C\\Z_C\\1\end{bmatrix} = \begin{bmatrix}R&t\\0&1\end{bmatrix}\begin{bmatrix}X_W\\Y_W\\Z_W\\1\end{bmatrix}

$$
**相机坐标系 -> 图像坐标系**：
这个过程是真正的投影过程，基本原理是中心透视投影
$$
\left\{\begin{matrix}
 x=f\frac{X_C}{Z_C}\\
 y=f\frac{Y_C}{Z_C}
\end{matrix}\right.
$$
其中$f$是相机焦距。或者写成矩阵形式：
$$
Z_C\begin{bmatrix}x\\y\\1\end{bmatrix}=\begin{bmatrix}f&0&0\\0&f&0\\0&0&1\end{bmatrix}\begin{bmatrix}X_C\\Y_C\\Z_C\end{bmatrix}
$$
**图像坐标系 -> 像素坐标系**：
一般分为两个部分：
1. 根据一个像素占多少长度，将长度单位转换为像素单位
2. 将转换后的像素坐标进行平移，使坐标原点为左上角
$$
\left\{\begin{matrix}
 u=\frac{x}{dx}+u_0\\
 v=\frac{y}{dy}+v_0
\end{matrix}\right.
$$
或者写成矩阵形式：
$$
\begin{bmatrix}u\\v\\1\end{bmatrix}=\begin{bmatrix}\frac{1}{dx}&0&u_0\\0&\frac{1}{dy}&v_0\\0&0&1\end{bmatrix}\begin{bmatrix}x\\y\\1\end{bmatrix}
$$
以上总结之后就是：
$$
\begin{bmatrix}u\\v\\1\end{bmatrix}=\frac{1}{Z_C}\begin{bmatrix}\frac{1}{dx}&0&u_0\\0&\frac{1}{dy}&v_0\\0&0&1\end{bmatrix}\begin{bmatrix}f&0&0&0\\0&f&0&0\\0&0&1&0\end{bmatrix}\begin{bmatrix}R&t\\0&1\end{bmatrix}\begin{bmatrix}X_W\\Y_W\\Z_W\\1\end{bmatrix}
$$
其中为了凑矩阵行列，在矩阵中补了0列。进一步整理之后得到：
$$
\begin{bmatrix}u\\v\\1\end{bmatrix}=\frac{1}{Z_C}\begin{bmatrix}\frac{f}{dx}&0&u_0\\0&\frac{f}{dy}&v_0\\0&0&1\end{bmatrix}\begin{bmatrix}R&t\\0&1\end{bmatrix}\begin{bmatrix}X_W\\Y_W\\Z_W\\1\end{bmatrix}
$$
前一个矩阵称为相机内参（包含焦距和像素长度/像元尺寸），后一个矩阵称为相机外参（包含旋转变换和平移变换）

## 图像中物体大小计算

### 使用 OpenCV 从图像计算物体实际大小

#### 核心思路

已知相机内参（通过标定获得）和相机到物体的距离（飞行高度），通过图像中物体的像素尺寸反推实际尺寸。

#### 前提条件

1. **相机内参矩阵** $K$（通过 `cv2.calibrateCamera` 标定获得）
2. **相机到物体的距离** $Z_C$（可从飞控高度 + 物体已知高度计算）
3. **物体在图像中的像素尺寸**（通过 YOLO / HoughCircles 检测获得）

#### 单目测距公式

从针孔相机模型推导（详见上文坐标系转换）：

假设物体实际宽度为 $W$（世界单位），图像中像素宽为 $w$（pixel），相机到物体的距离为 $Z_C$：

$$W = \frac{w \cdot Z_C}{f_x}$$

其中 $f_x = f / dx$ 是内参矩阵中的焦距（以像素为单位）。

同理，物体实际高度 $H$：$H = \frac{h \cdot Z_C}{f_y}$

#### OpenCV 标定与计算代码

##### 步骤 1：相机标定（棋盘格法）

```python
import cv2
import numpy as np
import glob

def calibrate_camera(checkerboard_pattern, square_size_mm=25, board_size=(9, 6)):
    """
    标定相机，获得内参矩阵和畸变系数
    checkerboard_pattern: 棋盘格图片路径，如 './calib/*.jpg'
    square_size_mm: 棋盘格方格实际尺寸（mm）
    board_size: 棋盘格内角点数量
    返回: (camera_matrix_3x3, dist_coeffs)
    """
    objp = np.zeros((board_size[0] * board_size[1], 3), np.float32)
    objp[:, :2] = np.mgrid[0:board_size[0], 0:board_size[1]].T.reshape(-1, 2)
    objp *= square_size_mm / 1000.0  # 转换为米

    obj_points = []  # 世界坐标点
    img_points = []  # 图像坐标点

    for fname in glob.glob(checkerboard_pattern):
        img = cv2.imread(fname)
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

        ret, corners = cv2.findChessboardCorners(gray, board_size, None)
        if ret:
            obj_points.append(objp)
            refined = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1),
                        (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001))
            img_points.append(refined)

    ret, mtx, dist, rvecs, tvecs = cv2.calibrateCamera(
        obj_points, img_points, gray.shape[::-1], None, None
    )

    print("内参矩阵 K:\n", mtx)
    print("畸变系数:\n", dist.ravel())
    return mtx, dist
```

##### 步骤 2：核心计算类

```python
class ObjectSizeCalculator:
    """利用针孔相机模型从图像计算物体实际尺寸和 NED 位置"""

    def __init__(self, camera_matrix, dist_coeffs=None):
        self.K = camera_matrix          # 3x3 内参矩阵
        self.fx = camera_matrix[0, 0]   # 焦距 x (pixel)
        self.fy = camera_matrix[1, 1]   # 焦距 y (pixel)
        self.cx = camera_matrix[0, 2]   # 像主点 x
        self.cy = camera_matrix[1, 2]   # 像主点 y
        self.dist = dist_coeffs

    def compute_real_size(self, pixel_width, pixel_height, distance_z):
        """
        据图像中物体的像素尺寸和相机距离，计算物体的实际尺寸

        Parameters:
            pixel_width  - 物体在图像中的像素宽度
            pixel_height - 物体在图像中的像素高度
            distance_z   - 相机到物体的距离（米）

        Returns:
            (real_width_m, real_height_m) 实际宽度和高度（米）
        """
        real_width = (pixel_width * distance_z) / self.fx
        real_height = (pixel_height * distance_z) / self.fy
        return real_width, real_height

    def pixel_to_ned_offset(self, pixel_u, pixel_v, distance_z):
        """
        将图像像素坐标转换为 NED 偏移（相对于相机光心在地面的投影）

        适用场景：已知圆筒中心在图像中的像素坐标(u,v)，
                 计算圆筒相对于飞行器的水平位置偏移

        Parameters:
            pixel_u, pixel_v - 物体中心在图像中的像素坐标
            distance_z       - 相机到物体的距离（米）

        Returns:
            (offset_x_m, offset_y_m) - NED 坐标系下的水平偏移（米）
              offset_x_m > 0 表示物体在飞行器前方（North）
              offset_y_m > 0 表示物体在飞行器右方（East）
        """
        # 像素偏差（相对于图像中心）
        du = pixel_u - self.cx
        dv = pixel_v - self.cy

        # 针孔模型反算世界坐标偏移
        offset_x_m = (du * distance_z) / self.fx
        offset_y_m = (dv * distance_z) / self.fy
        return offset_x_m, offset_y_m

    def pnp_solve_position(self, image_points, object_points):
        """
        使用 PnP 解算物体相对相机的位置（更精确的方法，适合已知物体几何的情况）

        Parameters:
            image_points  - Nx2 图像中物体特征点的像素坐标
            object_points - Nx3 物体特征点在世界坐标系下的坐标（已知尺寸）

        Returns:
            (rvec, tvec) - 旋转向量和平移向量
              tvec[0] = X (右/East), tvec[1] = Y (下/Down), tvec[2] = Z (前/North)
        """
        success, rvec, tvec = cv2.solvePnP(
            object_points.astype(np.float32),
            image_points.astype(np.float32),
            self.K,
            self.dist if self.dist is not None else np.zeros((4, 1)),
            flags=cv2.SOLVEPNP_ITERATIVE
        )
        if not success:
            return None, None
        return rvec, tvec
```

#### 投放区检测完整工作流

以下是将上述方法串接到 [[圆筒检测与投放]] 任务中的完整视觉处理流程：

##### 输入与坐标系约定

- **相机指向**：下视（垂直向下），图像上边 = 飞行器前方（North），图像右边 = 飞行器右方（East）
- **已知量**：
  - 相机内参 $K$（标定获得）
  - 当前飞行高度 $H$（来自飞控 `telemetry.position().relative_altitude_m`）
  - 圆筒实际高度：投放区 30cm，侦察区 15cm
- **需要求**：每个圆筒的 NED 坐标（相对飞行器）+ 判定其直径类型

##### 完整流程代码

```python
import cv2
import numpy as np
from dataclasses import dataclass
from typing import List, Optional, Tuple

@dataclass
class Cylinder:
    """圆筒检测结果"""
    bbox: Tuple[int, int, int, int]  # YOLO bbox (x, y, w, h)
    center_uv: Tuple[float, float]   # 圆筒中心像素坐标
    diameter_px: float               # 检测到的像素直径
    estimated_diameter_cm: float     # 估计的实际直径 (cm)
    ned_offset: Tuple[float, float]  # NED 水平偏移 (m)
    cylinder_type: Optional[int]     # 判定类型: 1=15cm, 2=20cm, 3=25cm, None=不确定


class DropZoneDetector:
    """
    投放区圆筒检测器 — 整合 YOLO + OpenCV + 针孔模型

    工作流: YOLO 粗检测 → HoughCircles 精定位 → 针孔模型计算 NED 偏移 → 判定圆筒类型
    """

    def __init__(self, yolo_model_path: str, camera_matrix: np.ndarray,
                 dist_coeffs: Optional[np.ndarray] = None):
        # YOLO
        from ultralytics import YOLO
        self.yolo = YOLO(yolo_model_path)
        # 针孔模型计算器
        self.calc = ObjectSizeCalculator(camera_matrix, dist_coeffs)

        # 相机 FOV 参数（用于判断圆筒是否在视野内）
        self.fov_h = 2 * np.arctan(camera_matrix[0, 2] / camera_matrix[0, 0])  # 水平半 FOV
        self.fov_v = 2 * np.arctan(camera_matrix[1, 2] / camera_matrix[1, 1])  # 垂直半 FOV

        # 圆筒实际直径 (m)
        self.CYLINDER_DIAMETERS = {1: 0.15, 2: 0.20, 3: 0.25}

    def detect_cylinders(self, frame: np.ndarray, flight_altitude: float
                         ) -> List[Cylinder]:
        """
        完整检测流程: 从单帧图像中检测并定位所有圆筒

        Args:
            frame: 来自下视摄像头的 BGR 图像
            flight_altitude: 飞行器距地面的高度 (m)，来自飞控遥测

        Returns:
            检测到的圆筒列表，按优先级（直径小→大）排列
        """
        results = []

        # ---- Step 1: YOLO 粗检测 ----
        yolo_results = self.yolo(frame, verbose=False)
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # 相机到圆筒顶部的真实距离（飞行高度 - 圆筒高度 30cm）
        camera_to_cylinder_z = flight_altitude - 0.30

        for box in yolo_results[0].boxes:
            x1, y1, x2, y2 = map(int, box.xyxy[0].tolist())
            conf = float(box.conf[0])
            if conf < 0.5:
                continue

            # ---- Step 2: 在 YOLO bbox 区域内 HoughCircles 精定位 ----
            x1c = max(x1 - 10, 0)
            y1c = max(y1 - 10, 0)
            x2c = min(x2 + 10, frame.shape[1])
            y2c = min(y2 + 10, frame.shape[0])
            roi = gray[y1c:y2c, x1c:x2c]

            # 根据飞行高度预估圆筒在图像中的像素半径范围
            # 15cm 圆筒 @ 7m ≈ 8-9px 半径; @ 2m ≈ 30px 半径
            min_r, max_r = self._estimate_radius_range(flight_altitude)

            circles = cv2.HoughCircles(
                roi, cv2.HOUGH_GRADIENT, dp=1.2, minDist=30,
                param1=50, param2=30,
                minRadius=min_r, maxRadius=max_r
            )

            if circles is None:
                continue

            # 取置信度最高的圆
            circles = np.uint16(np.around(circles[0]))
            best = max(circles, key=lambda c: c[2])  # c = (x, y, r)，选 r 最大的
            cx_roi, cy_roi, radius = best
            cx = cx_roi + x1c   # 转回全图坐标
            cy = cy_roi + y1c

            # ---- Step 3: 计算实际尺寸 ----
            real_w, _ = self.calc.compute_real_size(radius * 2, radius * 2,
                                                     camera_to_cylinder_z)

            # ---- Step 4: 计算 NED 偏移 ----
            offset_x, offset_y = self.calc.pixel_to_ned_offset(
                cx, cy, camera_to_cylinder_z)

            # ---- Step 5: 判定圆筒类型 ----
            cyl_type = self._classify_cylinder(real_w, flight_altitude)

            cylinder = Cylinder(
                bbox=(x1, y1, x2 - x1, y2 - y1),
                center_uv=(float(cx), float(cy)),
                diameter_px=float(radius * 2),
                estimated_diameter_cm=real_w * 100,
                ned_offset=(offset_x, offset_y),
                cylinder_type=cyl_type
            )
            results.append(cylinder)

        # 按直径从小到大排序（小圆筒优先级最高）
        results.sort(key=lambda c: c.estimated_diameter_cm)
        return results

    def _estimate_radius_range(self, altitude: float) -> Tuple[int, int]:
        """根据飞行高度预估圆筒在图像中的像素半径范围"""
        # 15cm 圆筒: r_px = (0.15 * fx) / (2 * altitude)
        min_r_px = int((0.15 * self.calc.fx) / (2 * altitude) * 0.7)
        # 25cm 圆筒: r_px = (0.25 * fx) / (2 * altitude)
        max_r_px = int((0.25 * self.calc.fx) / (2 * altitude) * 1.3)
        return max(min_r_px, 3), max(max_r_px, 5)

    def _classify_cylinder(self, estimated_diameter_m: float,
                           altitude: float) -> Optional[int]:
        """
        根据估计直径判定圆筒类型 (1/2/3 = 15/20/25 cm)

        在低空 (< 3m): 精度高，用绝对阈值
        在高空 (≥ 3m): 精度低，用宽松范围，可能返回 None
        """
        d_cm = estimated_diameter_m * 100

        if altitude < 3.0:
            # 低空精确判定
            if d_cm < 17.5:
                return 1
            elif d_cm < 22.5:
                return 2
            else:
                return 3
        else:
            # 高空粗略判定
            if d_cm < 18:
                return 1   # 大概率 15cm
            elif d_cm < 23:
                return 2   # 大概率 20cm
            elif d_cm > 22:
                return 3   # 大概率 25cm
            else:
                return None  # 不确定

    def select_targets(self, cylinders: List[Cylinder]) -> Tuple[Cylinder, Cylinder]:
        """
        从检测结果中选择两个目标圆筒（投放策略）

        优先选 1 号筒 (15cm = 500 分)，其次 2 号筒 (20cm = 300 分)
        如果两个 1 号筒不可行（比赛中只有 1 个 1 号筒），选 1 号+2 号
        """
        type1 = [c for c in cylinders if c.cylinder_type == 1]
        type2 = [c for c in cylinders if c.cylinder_type == 2]
        type3 = [c for c in cylinders if c.cylinder_type == 3]

        # 策略: 1 号筒优先，如果只检测到 1 个或 0 个再降级
        if len(type1) >= 1:
            first = type1[0]
            second = type2[0] if type2 else (type3[0] if type3 else type1[0])
        elif len(type2) >= 1:
            first = type2[0]
            second = type3[0] if type3 else type2[0]
        else:
            first = type3[0] if type3 else cylinders[0]
            second = cylinders[1] if len(cylinders) > 1 else first

        return first, second

    def cover_zone_check(self, flight_altitude: float, zone_size: Tuple[float, float]
                         ) -> bool:
        """
        检查在给定高度下相机能否覆盖整个区域

        Args:
            flight_altitude: 飞行高度 (m)
            zone_size: 区域宽高 (m)，如投放区 (8, 5)

        Returns:
            True 如果整个区域都在视野内
        """
        h_coverage = 2 * flight_altitude * np.tan(self.fov_h)
        v_coverage = 2 * flight_altitude * np.tan(self.fov_v)
        return h_coverage >= zone_size[0] and v_coverage >= zone_size[1]
```

##### 视觉伺服控制回路集成

```python
async def visual_servo_loop(drone, detector, target_cylinder, flight_altitude):
    """
    视觉伺服回路: 持续检测 → 计算偏移 → 发送速度指令 → 直到对准

    此函数应在一个独立的 asyncio Task 中运行，与 offboard setpoint 发送并行
    """
    Kp_xy = 0.5    # PID 比例系数（需要实际调参）
    threshold = 0.05  # 对准阈值 5cm

    while True:
        # 1. 捕获图像
        frame = capture_camera_frame()  # 通过 cv2.VideoCapture 获取

        # 2. 检测圆筒
        cylinders = detector.detect_cylinders(frame, flight_altitude)

        # 3. 找到目标圆筒
        cy = None
        for c in cylinders:
            # 通过 NED 偏移最近的匹配目标（简化版；实际应用中用 ID 追踪）
            cy = c
            break

        if cy is None:
            # 丢失目标 → 悬停等待
            yield VelocityNedYaw(0.0, 0.0, 0.0, 0.0)
            continue

        offset_x, offset_y = cy.ned_offset

        # 4. 判断是否已对准
        if abs(offset_x) < threshold and abs(offset_y) < threshold:
            # 已对准 → 发送零速度（悬停）并退出
            yield VelocityNedYaw(0.0, 0.0, 0.0, 0.0)
            break

        # 5. 计算速度指令（P 控制）
        vx = np.clip(Kp_xy * offset_x, -2.0, 2.0)
        vy = np.clip(Kp_xy * offset_y, -2.0, 2.0)
        yield VelocityNedYaw(vx, vy, 0.0, 0.0)
```

```python
def example_full_workflow():
    """完整工作流示例"""

    # 假设已完成标定
    K = np.array([[800,   0, 640],
                  [  0, 800, 480],
                  [  0,   0,   1]], dtype=np.float32)

    detector = DropZoneDetector(
        yolo_model_path="models/cylinder_yolov8n.pt",
        camera_matrix=K
    )

    # 检查 7m 高度下能否覆盖 8×5m 投放区

              f"NED偏移=({c.ned_offset[0]:.2f}, {c.ned_offset[1]:.2f})m")
```
