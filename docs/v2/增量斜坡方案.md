# 增量斜坡（Incremental Setpoint Ramping）

> 通过逐周期小步推进 position setpoint 来控制飞行速度，替代 PX4 位置控制器的自主调速。

---

## 一、问题

当前 `_fly_to_target` 一步把 setpoint 跳到最终航点，PX4 看到巨大位置误差后全力输出：

```
setpoint ●────────────────────────────● 目标航点 (6m 外)
           ↑
           └── 无人机当前位置

PX4 位置误差 = 6m → 全力输出 → 加速到 MPC_XY_VEL_MAX (~12m/s)
```

视觉检测要求 ~3m/s。12m/s 下运动模糊导致 YOLO+HoughCircles 全部失败。

## 二、核心思想

**不跳 setpoint，而是每周期把它向目标方向推一小步：**

```
周期 0:  setpoint ●                        目标 ●
                  ↑ drone

周期 1:          setpoint ●─→              目标 ●   推进一步
                           ↑ drone

周期 2:                   setpoint ●─→     目标 ●   再推进一步
                                    ↑ drone

周期 N:                                    setpoint●目标 ●  到达
                                                   ↑ drone 已跟上
```

每周期推进距离：

```
step = SEARCH_SPEED_MPS / FSM_LOOP_HZ
     = 3.0 / 20
     = 0.15 m/周期
```

## 三、为什么能限速

PX4 位置控制器：

```
vel_cmd = P_gain × position_error
vel_cmd = clamp(vel_cmd, -MPC_XY_VEL_MAX, +MPC_XY_VEL_MAX)
```

| 做法 | 位置误差 | 控制器输出 |
|------|---------|-----------|
| 一步跳 6m | 6m | 饱和到 MPC_XY_VEL_MAX |
| 每步推 0.15m | ~0.15m | 很小，远低于上限 |

位置误差始终很小 → 控制器不会饱和 → 速度被有效限制。

## 四、⚠️ 纯位置模式的追踪滞后

PX4 默认 `MPC_XY_P = 1.0`。纯 P 控制器在稳态下存在固有滞后：

```
实际速度 = MPC_XY_P × 稳态位置误差

稳态位置误差 = 实际速度 / MPC_XY_P
            = 3 m/s / 1.0
            = 3 m
```

**无人机会滞后 setpoint 约 3 米：**

```
setpoint ●────── 3m ──────● drone
  (一直往前挪)              (以 3m/s 跟着，永远落后 3m)
```

对搜索航线来说这个滞后可接受——覆盖区域不变，只是"晚到"。要消除滞后需用 `set_position_velocity_ned`。

## 五、两种实现对比

| 维度 | 纯位置 `set_position_ned` | 位置+速度 `set_position_velocity_ned` |
|------|--------------------------|--------------------------------------|
| setpoint 移动方式 | 增量推进 | 增量推进（同上） |
| 速度控制来源 | 位置环 P 增益 | 速度前馈 = SEARCH_SPEED_MPS（主导） |
| 稳态追踪滞后 | ~3m（MPC_XY_P=1 时） | 接近 0 |
| 拐角过渡 | 滞后导致拐弯"抹角" | 速度方向直接切换，转弯更利落 |
| 心跳改造 | 不需要 | 需要三种 setpoint 类型支持 |
| 推荐场景 | 快速验证、地面测试 | 正式飞行、比赛 |

稳态行为示意：

```
纯位置:
  setpoint ●──────────────────────→
                                    drone ●──────────────→
                                    (滞后 ~3m)

位置+速度:
  setpoint ●──────────────────────→
  drone   ●──────────────────────→
  (滞后 ~0m，速度前馈直接驱动机体)
```

## 六、纯位置版实现（不改心跳）

```python
async def _fly_to_target(self, interface, wp_idx):
    """
    增量斜坡 —— 纯位置模式。

    每周期将 setpoint 从 drones 当前位置向目标推进 step 距离。
    不改心跳，不引入速度前馈。
    代价：稳态追踪滞后 ≈ SEARCH_SPEED_MPS / MPC_XY_P。
    """
    x, y, z, speed = self._rect_waypoints[wp_idx]
    target_ned = interface.field_to_ned(x, y, z)

    # ---- 1. 获取当前位置 ----
    pos = await interface.get_position_ned()
    dn = target_ned.north_m - pos.north_m
    de = target_ned.east_m - pos.east_m
    dist = math.hypot(dn, de)

    # ---- 2. 到达判据（相对误差） ----
    seg_length = self._segment_lengths[wp_idx]
    if dist < seg_length * ARRIVAL_REL_THRESHOLD:
        # 已到达：setpoint snap 到航点，悬停
        interface.update_setpoint(target_ned)
        return True

    # ---- 3. 本周期只推进 step 距离 ----
    step = speed / FSM_LOOP_HZ          # 3.0/20 = 0.15m
    frac = step / dist if dist > 0 else 1.0
    if frac > 1.0:
        frac = 1.0                      # 最后一步直接到目标

    # ---- 4. 中间 setpoint = 当前位置 + 方向 × step ----
    intermediate = PositionNedYaw(
        pos.north_m + dn * frac,       # N: 从当前位置向目标挪 step
        pos.east_m  + de * frac,       # E: 同上
        target_ned.down_m,             # Z: 直接 snap 到巡航高度
        target_ned.yaw_deg,
    )
    interface.update_setpoint(intermediate)

    return False  # 还在路上
```

### 关键细节

| 细节 | 原因 |
|------|------|
| `pos.north_m + dn * frac` | 从**无人机当前位置**向目标推进，不是从上周期 setpoint。保证即使有风或干扰，setpoint 始终在前方固定距离处，不会越跑越远 |
| `target_ned.down_m` 直接 snap | 高度控制不需要限速，PX4 的 MPC_Z_VEL_MAX_UP/DN 已足够安全 |
| `frac > 1.0` 保护 | 最后一段距离 < step 时直接到目标 |
| 到达后 snap | `update_setpoint(target_ned)` 确保精确停在航点，不残留小数误差 |

## 七、位置+速度版实现（消除滞后）

```python
async def _fly_to_target(self, interface, wp_idx):
    x, y, z, speed = self._rect_waypoints[wp_idx]
    target_ned = interface.field_to_ned(x, y, z)

    pos = await interface.get_position_ned()
    dn = target_ned.north_m - pos.north_m
    de = target_ned.east_m - pos.east_m
    dist = math.hypot(dn, de)

    seg_length = self._segment_lengths[wp_idx]
    if dist < seg_length * ARRIVAL_REL_THRESHOLD:
        # 到达：velocity 归零，position snap
        interface.update_position_velocity_setpoint(
            target_ned,
            VelocityNedYaw(0, 0, 0, target_ned.yaw_deg))
        return True

    step = speed / FSM_LOOP_HZ
    frac = step / dist if dist > 0 else 1.0
    if frac > 1.0:
        frac = 1.0

    intermediate = PositionNedYaw(
        pos.north_m + dn * frac,
        pos.east_m  + de * frac,
        target_ned.down_m,
        target_ned.yaw_deg,
    )
    # 速度前馈：方向始终指向目标，大小 = SEARCH_SPEED_MPS
    vel = VelocityNedYaw(
        (dn / dist) * speed if dist > 0 else 0,
        (de / dist) * speed if dist > 0 else 0,
        0,                              # 高度不设速度前馈
        target_ned.yaw_deg,
    )
    interface.update_position_velocity_setpoint(intermediate, vel)
    return False
```

与纯位置版唯一区别：额外传 `vel`（速度前馈）。PX4 速度环直接拿到 3m/s 目标，不等位置环慢慢积误差 → 零滞后。

## 八、逐周期走一遍（以纯位置版为例）

从 P1 飞向 P2，距离 6m，速度 3m/s，MPC_XY_P = 1.0：

```
周期  elapsed  无人机位置     setpoint      误差     P×误差    实际速度
────  ────────  ────────────  ──────────    ────    ──────    ────────
 0    0.00s    N=28.50 E=0   N=28.65 E=0   0.15m   0.15m/s   开始加速
 1    0.05s    N=28.55 E=0   N=28.70 E=0   0.15m   0.15m/s   加速中
 2    0.10s    N=28.80 E=0   N=28.95 E=0   0.15m   0.15m/s   加速中
 ...
10    0.50s    N=29.80 E=0   N=29.95 E=0   0.15m   0.15m/s   加速中
...
稳态  ...      N≈setpoint    N≈drone_pos    ~3m*    ~3m/s*    ≈3m/s
              -3m           +3m
...
38    1.90s    N=34.20 E=0   N=34.30 E=0   0.10m   到达判定触发
39    1.95s    N=34.30 E=0   snap 到 P2     0.00m   → 悬停

* 注：稳态时误差 ≈ 3m/s / 1.0 = 3m，这是纯 P 控制器固有滞后。
  位置+速度版无此滞后。
```

## 九、矩形航线全流程

```
enter:
  生成四顶点 (SW → NW → NE → SE)
  预计算 4 段航段长度
  _wp_index = 0

execute:
  ┌─→ _fly_to_target(P1):
  │     每周期: setpoint 向 P1 推进 0.15m
  │     到达 → True
  │
  ├─→ _wp_index = 1（无目标，下一帧继续）
  │
  ├─→ _fly_to_target(P2):
  │     方向从 N 切到 E ← 拐角
  │     到达 → True
  │
  ├─→ _wp_index = 2
  │
  ├─→ _fly_to_target(P3):
  │     方向从 E 切到 -N
  │     到达 → True
  │
  ├─→ _wp_index = 3
  │
  └─→ _fly_to_target(P4):
        方向从 -N 切到 -E
        到达 → True
        _wp_index = 0 → 循环回 P1
```

## 十、与 MPC_XY_VEL_MAX 参数配合（安全兜底）

增量斜坡控制速度 + PX4 参数限速作为兜底：

```
MPC_XY_VEL_MAX = SEARCH_SPEED_MPS × 1.2    ← 硬件兜底
                                             即使增量斜坡代码有 bug
                                             也不会超过此速度
增量斜坡 setpoint                            ← 精确速度控制
                                             平稳恒定
```

参数设置时机：在进入搜索状态前的 TransitState 中提前设置（避免 param 写入延迟）。

```python
# TransitState 或 PrepareSearchState.enter()
await interface.drone.param.set_param_float("MPC_XY_VEL_MAX", SEARCH_SPEED_MPS * 1.2)
await interface.drone.param.set_param_float("MPC_ACC_HOR", 2.0)  # 降低加速度，更柔和
```

恢复：在搜索完成/任务结束/RTL 时恢复原始值。

## 十一、相关参数

| 参数 | 文件 | 说明 |
|------|------|------|
| `SEARCH_SPEED_MPS` | config.py | 搜索矩形航线飞行速度，默认 3.0 m/s |
| `FSM_LOOP_HZ` | config.py | FSM 主循环频率，决定 step 粒度，默认 20 Hz |
| `ARRIVAL_REL_THRESHOLD` | config.py | 航点到达判据，剩余 < 航段×5% 即到达 |
| `MPC_XY_VEL_MAX` | PX4 参数 | 位置控制器最大水平速度，兜底上限 |
| `MPC_XY_P` | PX4 参数 | 位置环 P 增益，决定纯位置模式的稳态滞后量 |
| `MPC_ACC_HOR` | PX4 参数 | 水平最大加速度，降低可减轻起停时的运动模糊 |
