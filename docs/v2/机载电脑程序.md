## 二、整体任务流程

```
按下计时器 → Arm（记录Home点）
    │
    ▼
TakeoffState(7m) → HoverState(1s)
    │
    ▼
TransitState(x=30, z=7) → HoverState(1s)
    │
    ▼
SearchState()  ← 粗检测仅执行一次：7m 高度检测全部圆筒，选定两个目标
    │
    ├── AlignState(bottle=1) → DropState(bottle=1)
    │     ├─ 下降至 2-3m
    │     ├─ 视觉伺服对准
    │     └─ 舵机释放第1瓶
    │
    ├── AlignState(bottle=2) → DropState(bottle=2)
    │     ├─ 上升至 3-4m
    │     ├─ 平移至第2个目标圆筒
    │     ├─ 视觉伺服对准
    │     └─ 舵机释放第2瓶
    │
    ▼
TransitState(x=55, z=7) → HoverState(1s)
    │
    ▼
ReconState()
    │  ├─ 下降至 2-3m
    │  ├─ 沿预设矩形航线扫描侦察区
    │  └─ 通过图传将标识图像传回地面站
    │
    ▼
TransitState(x=0, z=5) → HoverState(1s)
    │
    ▼
PrecisionLandState()
    │  ├─ 方案A: 搜索"H"标识 → 视觉伺服对准 → 着陆
    │  └─ 方案B (兜底): 飞回(0,0,0) → 低空下降率控制着陆
    │
    ▼
Disarm → 停表 → 填写成绩单
```

### 关键规则约束

- **全程自主**，不允许任何人工操纵（除紧急停止）
- **5 分钟**内完成全部任务
- 两个载荷均投至投放区、且至少一个投至有效区，才可继续侦察
- 侦察分：正确 +100，错误 −100（谨慎策略：不确定宁可不填）
- 完赛才能获得时间分

## 三、interface.py — PX4 通信层

通信层封装所有与飞控的交互，对外暴露统一的异步接口。三个内置保护机制：

### 3.1 全局健康看门狗（Global Guard）

在主循环中，执行任何状态逻辑前，先运行一次健康检查。无论当前处于什么状态，一旦检测到异常立即强制悬停。

```python
import asyncio
from dataclasses import dataclass
from typing import Optional, Callable
from mavsdk import System
from mavsdk.offboard import PositionNedYaw, VelocityNedYaw

@dataclass
class HealthStatus:
    """飞控健康状态快照"""
    is_connected: bool = False
    is_armed: bool = False
    is_offboard: bool = False
    is_global_position_ok: bool = False
    is_home_position_ok: bool = False
    battery_pct: float = 100.0
    estimator_flags_ok: bool = True
    gps_fix_type: int = 0

    @property
    def is_healthy(self) -> bool:
        from config import BATTERY_LOW_THRESHOLD_PCT, GPS_FIX_MIN
        return (self.is_connected and self.is_armed and self.is_offboard
                and self.is_global_position_ok and self.is_home_position_ok
                and self.battery_pct > BATTERY_LOW_THRESHOLD_PCT
                and self.estimator_flags_ok
                and self.gps_fix_type >= GPS_FIX_MIN)


class PX4Interface:
    """PX4 通信层 — 封装所有 MAVSDK 交互 + 保护机制"""

    def __init__(self, system_address: str = "udp://:14540",
                 on_unhealthy: Optional[Callable] = None):
        self.drone = System()
        self.system_address = system_address
        self.health = HealthStatus()
        self._on_unhealthy = on_unhealthy  # 外部回调，触发时切换到 HOVER

        # 心跳维持
        self._last_setpoint = PositionNedYaw(0.0, 0.0, 0.0, 0.0)
        self._setpoint_updated = False

        # 参数（FIELD_YAW_DEG 在 connect_and_setup 中 arm 时自动检测覆写）
        self.FIELD_YAW_DEG: float = 0.0

    # ---------- 生命周期 ----------

    async def connect_and_setup(self):
        await self.drone.connect(system_address=self.system_address)

        # 等待连接和 GPS
        async for state in self.drone.core.connection_state():
            if state.is_connected:
                break
        async for health in self.drone.telemetry.health():
            if health.is_global_position_ok and health.is_home_position_ok:
                break

        # 自动检测场地朝向：读取飞行器当前航向作为 FIELD_YAW_DEG
        # 前提：赛前将飞行器放在起降点，机头对准场地前方
        async for heading in self.drone.telemetry.heading():
            self.FIELD_YAW_DEG = heading.heading_deg
            print(f"[INFO] 场地朝向已自动检测: FIELD_YAW_DEG = {self.FIELD_YAW_DEG:.1f}°")
            break

        # 启动遥测监控 task
        asyncio.create_task(self._telemetry_watcher())

        # 启动心跳 task
        asyncio.create_task(self._heartbeat_loop())

    async def arm_and_offboard(self):
        await self.drone.action.arm()
        # Home 点在此刻由 PX4 自动记录
        await self.drone.offboard.set_position_ned(self._last_setpoint)
        await self.drone.offboard.start()

    async def disarm(self):
        await self.drone.offboard.stop()
        await self.drone.action.disarm()

    # ---------- 健康看门狗 ----------

    async def _telemetry_watcher(self):
        """持续更新健康状态快照 — 不阻塞，独立 task"""
        async for health in self.drone.telemetry.health():
            self.health.is_global_position_ok = health.is_global_position_ok
            self.health.is_home_position_ok = health.is_home_position_ok

        # 同时监控 estimator 状态（检测 RTK 精度突变）
        # 注意: MAVSDK Python 的 estimator 字段取决于版本，替代方案如下
        async for status_text in self.drone.telemetry.status_text():
            if "estimator" in status_text.text.lower():
                # 检测到 estimator 异常 → 回调外部处理
                if self._on_unhealthy:
                    self._on_unhealthy(status_text.text)

    async def _battery_watcher(self):
        async for battery in self.drone.telemetry.battery():
            self.health.battery_pct = battery.remaining_percent

    async def global_guard_check(self):
        """每个循环周期调用一次，返回 True 表示健康"""
        # 更新连接/武装/模式状态
        async for state in self.drone.core.connection_state():
            self.health.is_connected = state.is_connected
            break
        async for armed in self.drone.telemetry.armed():
            self.health.is_armed = armed
            break
        async for mode in self.drone.telemetry.flight_mode():
            self.health.is_offboard = (mode.name == "OFFBOARD")
            break

        return self.health.is_healthy

    # ---------- Offboard 心跳 ----------

    async def _heartbeat_loop(self):
        """
        独立 task，以固定频率发送 setpoint。
        如果主逻辑没有下发新指令，自动重发上一条指令（惰性保持）。
        PX4 要求 ≥2Hz 发送，此处以 20Hz 确保余量。
        """
        while True:
            await self.drone.offboard.set_position_ned(self._last_setpoint)
            self._setpoint_updated = False
            await asyncio.sleep(1.0 / OFFBOARD_HEARTBEAT_HZ)

    def update_setpoint(self, setpoint: PositionNedYaw):
        """主逻辑调用此方法下发新指令"""
        self._last_setpoint = setpoint
        self._setpoint_updated = True

    # ---------- 高层指令 ----------

    async def takeoff(self, altitude_m: float):
        await self.drone.action.set_takeoff_altitude(altitude_m)
        await self.drone.action.takeoff()

    async def set_actuator(self, index: int, value: float):
        await self.drone.action.set_actuator(index, value)

    async def land(self):
        await self.drone.action.land()

    # ---------- 遥测读取 ----------

    async def get_position_ned(self) -> PositionNedYaw:
        """获取当前 NED 位置（单次读取）"""
        async for pos in self.drone.telemetry.position():
            # telemetry.position() 返回的是 GPS 经纬度，不是 NED
            # 用 odometry 获取 NED
            break
        async for odom in self.drone.telemetry.odometry():
            return PositionNedYaw(
                odom.position_body.x_m if hasattr(odom, 'position_body') else 0.0,
                odom.position_body.y_m if hasattr(odom, 'position_body') else 0.0,
                0.0, 0.0
            )

    async def get_altitude(self) -> float:
        async for pos in self.drone.telemetry.position():
            return pos.relative_altitude_m

    # ---------- 场地坐标转换 ----------

    def field_to_ned(self, forward_m: float, right_m: float,
                     height_m: float) -> PositionNedYaw:
        """
        将场地坐标（前方/右方/高度）转换为 NED 坐标 + yaw

        NED 的 N 轴固定指向真北。场地"前方"可能不与真北重合，
        FIELD_YAW_DEG 记录场地前方对应的真北方位角。

        Args:
            forward_m: 场地前方距离 (m)
            right_m:   场地右方距离 (m)
            height_m:  飞行高度 (m)
        Returns:
            PositionNedYaw
        """
        import math
        theta = math.radians(self.FIELD_YAW_DEG)
        north_m = forward_m * math.cos(theta) - right_m * math.sin(theta)
        east_m  = forward_m * math.sin(theta) + right_m * math.cos(theta)
        return PositionNedYaw(north_m, east_m, -height_m, self.FIELD_YAW_DEG)
```

### 3.2 Offboard 心跳维持机制

PX4 Offboard 模式有严格的底层安全逻辑：
- 切换入 Offboard 前，必须已持续发送 setpoint 至少 1-2 秒
- 整个任务期间发送频率不能低于 **2Hz**
- 如果状态机在计算视觉误差时卡顿 0.5 秒没发指令，飞控将退出 Offboard 并触发保护（就地降落或返航）

**应对**：`_heartbeat_loop` 是一个独立的 asyncio Task，以 20Hz 持续发送 `_last_setpoint`。主逻辑只需调用 `update_setpoint()` 更新目标，心跳 task 自动维持——主逻辑即使卡顿几百毫秒也不会断连。

### 3.3 全局健康监控触发逻辑

```
每个主循环周期:
    if not interface.global_guard_check():
        → 强制切换到 HoverState(悬停) + 告警
        → 等待人工接管或自动恢复
```

应用场景：
- RTK 定位精度方差突增 → 不论当前是否在对准水桶，强制悬停
- 电池低于 20% → 触发返航而非继续任务
- GPS fix type < 3 → 定位不可靠，不能继续视觉导航

## 四、main_fsm.py — 状态机引擎

### 4.1 状态基类

```python
from abc import ABC, abstractmethod
import time
from typing import Optional

class BaseState(ABC):
    """所有状态的基类"""

    def __init__(self, name: str, timeout_s: Optional[float] = None):
        self.name = name
        self.timeout_s = timeout_s  # None = 无超时
        self._enter_time: Optional[float] = None
        self.is_completed = False
        self.error: Optional[str] = None

    async def enter(self, interface: "PX4Interface"):
        """进入状态时调用 — 记录时间戳，执行初始化"""
        self._enter_time = time.monotonic()
        self.is_completed = False
        self.error = None

    @abstractmethod
    async def execute(self, interface: "PX4Interface"):
        """每个主循环周期调用一次 — 返回 (completed, next_state_or_None)"""
        ...

    async def exit(self, interface: "PX4Interface"):
        """退出状态时调用 — 清理资源"""
        pass

    def elapsed(self) -> float:
        """当前状态已运行时间（秒）"""
        if self._enter_time is None:
            return 0.0
        return time.monotonic() - self._enter_time

    def is_timed_out(self) -> bool:
        """检查是否超时"""
        if self.timeout_s is None:
            return False
        return self.elapsed() > self.timeout_s
```

### 4.2 主循环

```python
import asyncio

class MissionFSM:
    """任务状态机引擎"""

    def __init__(self, interface: PX4Interface):
        self.interface = interface
        self.mission_queue: list[BaseState] = []
        self.current_state: Optional[BaseState] = None
        self.state_index = 0

        # 注册不健康回调
        interface._on_unhealthy = self._handle_unhealthy

    def build_mission(self):
        """构建任务序列
        投放流程: SearchState(粗检测一次) → AlignState+DropState(每瓶)
        """
        from config import (
            CRUISE_ALTITUDE_M, DROP_ZONE_DISTANCE_M, RECON_ZONE_DISTANCE_M,
            LAND_START_ALTITUDE_M, TRANSIT_SPEED_MPS,
        )

        self.mission_queue = [
            TakeoffState(target_alt=CRUISE_ALTITUDE_M, timeout_s=30),
            HoverState(hover_time=1.0),

            TransitState(x=DROP_ZONE_DISTANCE_M, y=0.0, z=CRUISE_ALTITUDE_M,
                         speed=TRANSIT_SPEED_MPS, timeout_s=30),
            HoverState(hover_time=1.0),

            # 投放：粗检测仅一次
            SearchState(timeout_s=30),
            # 第一瓶：下降对准 → 投放
            AlignState(bottle_index=1, timeout_s=60),
            DropState(bottle_index=1, timeout_s=10),
            # 第二瓶：平移对准 → 投放
            AlignState(bottle_index=2, timeout_s=60),
            DropState(bottle_index=2, timeout_s=10),

            TransitState(x=RECON_ZONE_DISTANCE_M, y=0.0, z=CRUISE_ALTITUDE_M,
                         speed=TRANSIT_SPEED_MPS, timeout_s=30),
            HoverState(hover_time=1.0),
            ReconState(timeout_s=120),

            TransitState(x=0.0, y=0.0, z=LAND_START_ALTITUDE_M,
                         speed=TRANSIT_SPEED_MPS, timeout_s=60),
            HoverState(hover_time=1.0),
            PrecisionLandState(timeout_s=60),
        ]
        self.state_index = 0

    async def run(self):
        """主循环"""
        self.build_mission()
        await self.interface.connect_and_setup()
        await self.interface.arm_and_offboard()

        while self.state_index < len(self.mission_queue):
            state = self.mission_queue[self.state_index]
            self.current_state = state

            # ---- 0. 全局健康检查 ----
            if not await self.interface.global_guard_check():
                await self._handle_unhealthy("global_guard failed")
                break  # 悬停等待，不再继续任务

            # ---- 1. 进入状态 ----
            await state.enter(self.interface)

            # ---- 2. 执行循环 ----
            while True:
                # 每周期健康检查
                if not await self.interface.global_guard_check():
                    await self._handle_unhealthy("health check in state")
                    return

                try:
                    done, next_state = await state.execute(self.interface)
                except Exception as e:
                    state.error = str(e)
                    await self._handle_state_error(state, e)
                    break

                if done:
                    break
                await asyncio.sleep(1.0 / FSM_LOOP_HZ)

            # ---- 3. 退出状态 ----
            await state.exit(self.interface)

            # ---- 4. 超时处理 ----
            if state.is_timed_out() and not state.is_completed:
                print(f"[WARN] {state.name} 超时 ({state.timeout_s}s)，跳过")
                # 超时后根据需要决定是跳过还是重试

            self.state_index += 1

        # 任务结束
        await self.interface.disarm()

    async def _handle_unhealthy(self, reason: str):
        """不健康 → 切换到悬停"""
        print(f"[EMERGENCY] 全局健康检查失败: {reason}")
        self.interface.update_setpoint(
            PositionNedYaw(0.0, 0.0, 0.0, 0.0)
        )

    async def _handle_state_error(self, state: BaseState, error: Exception):
        """状态执行出错时的统一处理"""
        print(f"[ERROR] {state.name} 执行异常: {error}")
        # 发送悬停指令
        self.interface.update_setpoint(
            PositionNedYaw(0.0, 0.0, 0.0, 0.0)
        )
```

### 4.3 状态内超时机制

每个状态的 `__init__` 接受 `timeout_s` 参数，基类 `is_timed_out()` 通过 `enter()` 时记录的时间戳判断。状态在执行循环中可主动检查超时：

```python
async def execute(self, interface):
    if self.is_timed_out():
        # 超时 → 放弃当前目标，进入降级策略
        return True, None  # 让状态机自动推进到下一个状态
    # ... 正常逻辑 ...
```

各个状态设置最大生命周期，防止流程卡死。

### 5.3 TransitState — 航线飞行

```python
class TransitState(BaseState):
    """
    航线状态：以指定速度飞往场地坐标系中的目标位置

    Parameters:
        x, y, z: 场地坐标系目标 (前方/右方/高度, m)
        speed:   巡航速度 (m/s)
    """

    def __init__(self, x: float, y: float, z: float,
                 speed: float = TRANSIT_SPEED_MPS, timeout_s: float = 60):
        super().__init__("Transit", timeout_s)
        self.target_x, self.target_y, self.target_z = x, y, z
        self.speed = speed
        self._start_pos: Optional[PositionNedYaw] = None

    async def enter(self, interface):
        await super().enter(interface)
        # 转换场地坐标 → NED
        target_sp = interface.field_to_ned(self.target_x, self.target_y,
                                            self.target_z)
        interface.update_setpoint(target_sp)

    async def execute(self, interface):
        if self.is_timed_out():
            self.error = "transit timeout"
            return True, None

        alt = await interface.get_altitude()
        # 判断是否到达：接近目标高度 + 预估时间已过
        dist = (self.target_x ** 2 + self.target_y ** 2) ** 0.5
        est_time = dist / self.speed if self.speed > 0 else 10
        if (self.elapsed() > est_time
                and abs(alt - self.target_z) < 0.5):
            self.is_completed = True
            return True, None
        return False, None
```

关键：setpoint 更新通过 `interface.update_setpoint()` 下发，然后由 heartbeat task 以 20Hz 持续发送。TransitState 执行期间不需要自己发 setpoint。

### 5.4 SearchState — 粗检测（仅执行一次）

在 7m 安全高度对投放区做一次完整的 YOLO 检测，确定所有圆筒的 NED 坐标和类型，为两个水瓶分配目标。

> 详见 [[圆筒检测与投放#阶段一：粗检测]]

```python
class SearchState(BaseState):
    """
    粗检测状态 — 仅在 7m 高度执行一次。

    检测投放区 3 个圆筒 → 判定类型(15/20/25cm) → 选择两个投放目标
    结果存入 interface 的共享缓存，后续 AlignState 直接读取。
    """

    def __init__(self, timeout_s: float = 30):
        super().__init__("Search", timeout_s)

    async def enter(self, interface):
        await super().enter(interface)
        # 确保在巡航高度
        sp = interface.field_to_ned(DROP_ZONE_DISTANCE_M, 0.0, CRUISE_ALTITUDE_M)
        interface.update_setpoint(sp)

    async def execute(self, interface):
        if self.is_timed_out():
            self.error = "coarse search timeout"
            return True, None

        alt = await interface.get_altitude()
        if abs(alt - CRUISE_ALTITUDE_M) > 1.0:
            return False, None  # 高度未稳定

        # ---- 单次检测 ----
        frame = await capture_frame_async()
        cylinders = detector.detect_cylinders(frame, alt)

        if len(cylinders) < 2:
            # 检测到的圆筒不足 → 重试（YOLO 可能漏检）
            self.error = f"只检测到 {len(cylinders)} 个圆筒，需要至少 2 个"
            return False, None

        # 选择两个目标
        target1, target2 = detector.select_targets(cylinders)

        # 存入共享存储（供 AlignState 读取）
        interface.shared["drop_targets"] = (target1, target2)
        print(f"粗检测完成: 目标1={target1.cylinder_type}号筒, "
              f"目标2={target2.cylinder_type}号筒")
        print(f"  目标1 NED偏移: ({target1.ned_offset[0]:.2f}, {target1.ned_offset[1]:.2f})m")
        print(f"  目标2 NED偏移: ({target2.ned_offset[0]:.2f}, {target2.ned_offset[1]:.2f})m")

        self.is_completed = True
        return True, None
```

### 5.5 AlignState — 精对准

下降至目标圆筒上方 2-3m，通过视觉伺服 PID 对准圆筒中心。每个水瓶执行一次。

> 详见 [[圆筒检测与投放#阶段二：精对准]]

```python
class AlignState(BaseState):
    """
    精对齐状态：下降 + 视觉伺服对准圆筒

    bottle_index: 1 或 2，对应投放顺序
    目标圆筒信息从 SearchState 存入的 shared 缓存读取。
    """

    def __init__(self, bottle_index: int, timeout_s: float = 60):
        super().__init__("Align", timeout_s)
        self.bottle_index = bottle_index

        # 子阶段
        self.phase = "descend"  # descend → servo → done
        self._search_start = 0.0
        self._search_timeout = SEARCH_TIMEOUT_S
        self._align_threshold = ALIGN_THRESHOLD_M
        self._target = None

    async def enter(self, interface):
        await super().enter(interface)

        # 从共享缓存读取 SearchState 的结果
        targets = interface.shared.get("drop_targets")
        if targets is None:
            self.error = "未找到粗检测结果"
            return
        self._target = targets[0] if self.bottle_index == 1 else targets[1]

        if self._target is None:
            self.error = f"bottle_{self.bottle_index} 未分配目标"
            return

        # 下降至目标圆筒上方
        sp = interface.field_to_ned(
            DROP_ZONE_DISTANCE_M + self._target.ned_offset[0],
            self._target.ned_offset[1],
            DROP_ALIGN_ALTITUDE_M
        )
        interface.update_setpoint(sp)
        self.phase = "descend"
        self._search_start = self.elapsed()
        print(f"Align bottle_{self.bottle_index}: 下降至目标上方 2.5m")

    async def execute(self, interface):
        if self.is_timed_out():
            self.error = "align timeout"
            return True, None

        if self._target is None:
            return True, None  # enter 阶段出错，直接退出

        if self.phase == "descend":
            return await self._do_descend(interface)
        elif self.phase == "servo":
            return await self._do_visual_servo(interface)
        return False, None

    async def _do_descend(self, interface):
        """等待下降到 3m 以下"""
        alt = await interface.get_altitude()
        if alt <= 3.0:
            self.phase = "servo"
            self._search_start = self.elapsed()
        return False, None

    async def _do_visual_servo(self, interface):
        """
        视觉伺服循环：检测圆筒 → 计算 NED 偏移 → P 控制调整位置

        目标丢失时的搜索策略：
        - 3 秒内向最后已知方向慢速搜索
        - 超时后拉高重搜（放弃当前目标，进入降级）
        """
        alt = await interface.get_altitude()
        frame = await capture_frame_async()

        # 低空精检测
        cylinders = detector.detect_cylinders(frame, alt)
        best = self._match_target(cylinders)

        if best is None:
            # 目标丢失
            if self.elapsed() - self._search_start > self._search_timeout:
                print(f"[WARN] Align {self.bottle_index}: 目标丢失超时, 放弃")
                return True, None  # 放弃当前目标

            # 保持向已知位置慢速移动
            sp = interface.field_to_ned(
                DROP_ZONE_DISTANCE_M + self._target.ned_offset[0],
                self._target.ned_offset[1],
                alt
            )
            interface.update_setpoint(sp)
            return False, None

        self._search_start = self.elapsed()  # 重置搜索计时器

        offset_x, offset_y = best.ned_offset
        # 更新目标缓存（低空数据更精确）
        self._target = best

        if (abs(offset_x) < self._align_threshold
                and abs(offset_y) < self._align_threshold):
            # 已对准，更新共享缓存供 DropState 读取
            interface.shared[f"bottle_{self.bottle_index}_aligned"] = True
            interface.shared[f"bottle_{self.bottle_index}_position"] = best
            self.is_completed = True
            return True, None

        # P 控制微调位置
        sp = interface.field_to_ned(
            DROP_ZONE_DISTANCE_M + offset_x * VISUAL_SERVO_KP,
            offset_y * VISUAL_SERVO_KP,
            alt
        )
        interface.update_setpoint(sp)
        return False, None

    def _match_target(self, cylinders: list):
        """从检测结果中匹配目标圆筒"""
        if not cylinders:
            return None
        # 通过 NED 偏移最近匹配
        tx, ty = self._target.ned_offset
        best = min(cylinders,
                   key=lambda c: (c.ned_offset[0] - tx) ** 2
                               + (c.ned_offset[1] - ty) ** 2)
        return best
```

### 5.7 ReconState — 侦察

侦察策略为**预设矩形航线扫描**，只需沿航线飞过侦察区，通过图传将标识图像传回地面站供机组填写。

```python
class ReconState(BaseState):
    """
    侦察状态：沿侦察区预设矩形航线飞行，通过图传回传标识图像。

    侦察区 5 个圆筒 (直径 20cm, 高 15cm)，其中 3 个内置 12×12cm 危险品标识。
    航线覆盖整个 8×5m 侦察区域，在圆筒上方以 2-3m 高度飞过。
    机组通过图传实时观察，手动填写成绩记录单。
    """

    def __init__(self, timeout_s: float = 120):
        super().__init__("Recon", timeout_s)
        self._waypoints = []      # 航线点列表
        self._current_wp = 0      # 当前航点索引
        self._wp_phase = "transit"  # transit → hover → transit → ...

    async def enter(self, interface):
        await super().enter(interface)

        # 侦察区尺寸 8m × 5m，航线覆盖整个区域
        cx = RECON_ZONE_DISTANCE_M  # 侦察区中心距起降点
        cy = 0.0                    # 场地中线
        w, h = 4.0, 2.5             # 半宽半高
        step = RECON_SCAN_STEP_M    # 航线间距

        self._waypoints = [
            # 蛇形扫描路径
            (cx, cy + h, RECON_ALTITUDE_M),
            (cx, cy - h, RECON_ALTITUDE_M),
            (cx + step, cy - h, RECON_ALTITUDE_M),
            (cx + step, cy + h, RECON_ALTITUDE_M),
            (cx + 2 * step, cy + h, RECON_ALTITUDE_M),
            (cx + 2 * step, cy - h, RECON_ALTITUDE_M),
            (cx + w, cy - h, RECON_ALTITUDE_M),
        ]
        self._current_wp = 0

        # 发送第一个航点
        wp = self._waypoints[0]
        sp = interface.field_to_ned(*wp)
        interface.update_setpoint(sp)

        print(f"Recon: 开始矩形航线扫描, {len(self._waypoints)} 个航点")

    async def execute(self, interface):
        if self.is_timed_out():
            self.error = "recon timeout，已扫描的可用于填写"
            return True, None

        if self._current_wp >= len(self._waypoints):
            # 全部航点完毕
            print("Recon: 航线扫描完成")
            self.is_completed = True
            return True, None

        # 获取当前航点
        wp_x, wp_y, wp_z = self._waypoints[self._current_wp]
        alt = await interface.get_altitude()

        # 判断是否到达当前航点
        # （简化判定：高度接近 + 已飞行足够时间）
        dist_per_wp = 2.0  # 每个航点间距约 2-3m
        est_time = dist_per_wp / 3.0  # 以 3m/s 估计

        if (self.elapsed() > (self._current_wp + 1) * est_time
                and abs(alt - wp_z) < 0.5):
            self._current_wp += 1
            if self._current_wp < len(self._waypoints):
                # 发送下一个航点
                nx, ny, nz = self._waypoints[self._current_wp]
                sp = interface.field_to_ned(nx, ny, nz)
                interface.update_setpoint(sp)

        # 图传自动工作（独立线程/进程），此处只需确认图传正常
        return False, None
```

**设计要点**：
- 蛇形扫描确保覆盖整个 8×5m 侦察区
- 飞行高度 2.5m 时 20cm 圆筒清晰可见，12×12cm 标识可分辨
- 不需机载分类，图传直接回传图像给地面站，由机组人工判定
- 谨慎策略：侦察分 = +100 正确 −100 错误，不确定宁可不填（0 > −100）

### 5.8 PrecisionLandState — 精确着陆

两种方案，根据飞行器返航精度实测后决定使用哪种：

**方案 A**：直接飞回 Home 点 (0, 0, 0) → 低空时启用下降率控制 + 视觉微调
**方案 A**：视觉伺服对准 "H" 标识 → 缓慢下降 → AUTO.LAND


```python
class PrecisionLandState(BaseState):
    """
    精确着陆 — 双方案。

    方案 A（视觉优先）：下视搜索"H"标识 → 视觉伺服对准 80cm 圆 → 着陆
    方案 B（GPS兜底）：飞回 (0,0,0) Home 点 → 低空启用视觉微调 → 着陆

    实际使用哪个方案取决于飞行器返航 GPS 精度。
    """

    def __init__(self, timeout_s: float = 60, use_vision: bool = True):
        super().__init__("Land", timeout_s)
        self.use_vision = use_vision
        self._descend_rate = LAND_DESCEND_RATE_MPS
        self._landing_safe_alt = LAND_SAFE_ALTITUDE_M

    async def enter(self, interface):
        await super().enter(interface)
        # 飞到起降区上空
        sp = interface.field_to_ned(0.0, 0.0, LAND_START_ALTITUDE_M)
        interface.update_setpoint(sp)

    async def execute(self, interface):
        if self.is_timed_out():
            await interface.land()
            self.is_completed = True
            return True, None

        if self.use_vision:
            return await self._vision_landing(interface)
        else:
            return await self._gps_fallback_landing(interface)

    # ---- 方案 A: 视觉伺服对准 ----

    async def _vision_landing(self, interface):
        alt = await interface.get_altitude()
        frame = await capture_frame_async()
        h_offset = precision_landing.detect_h_marker(frame)

        if h_offset is None:
            # 没找到 H 标识 → 切换到方案 B 兜底
            print("[WARN] 未检测到 H 标识，切换至 GPS 兜底着陆")
            self.use_vision = False
            return False, None

        offset_x, offset_y = h_offset

        if abs(offset_x) < ALIGN_THRESHOLD_M and abs(offset_y) < ALIGN_THRESHOLD_M:
            if alt <= 0.8:
                await interface.land()
                self.is_completed = True
                return True, None
            else:
                # 对准但还高 → 持续下降
                sp = interface.field_to_ned(
                    0.0, 0.0, max(alt - self._descend_rate, 0.5)
                )
                interface.update_setpoint(sp)
        else:
            # 水平微调
            Kp = 0.3
            sp = interface.field_to_ned(
                offset_x * Kp,
                offset_y * Kp,
                alt
            )
            interface.update_setpoint(sp)

        return False, None

    # ---- 方案 B: GPS/Home 点兜底 ----

    async def _gps_fallback_landing(self, interface):
        """
        GPS 兜底着陆：
        1. 直接飞回 Home 点 (0, 0, 0)
        2. 下降到"着陆保险"高度 (2m) 以下时，降低下降率
        3. 如有视觉信号，用视觉微调下降率帮助对准
        """
        alt = await interface.get_altitude()

        if alt > self._landing_safe_alt:
            # 正常下降回 (0, 0, 0)
            sp = interface.field_to_ned(0.0, 0.0, max(alt - self._descend_rate, self._landing_safe_alt))
            interface.update_setpoint(sp)
            return False, None

        # 进入着陆保险阶段：高度 < 2m

        # 尝试获取视觉信号微调
        frame = await capture_frame_async()
        h_offset = precision_landing.detect_h_marker(frame)

        if h_offset is not None:
            offset_x, offset_y = h_offset
            # 根据偏移微调下降率（偏移大 → 慢降，偏移小 → 正常降）
            dist = (offset_x ** 2 + offset_y ** 2) ** 0.5
            rate = max(0.1, self._descend_rate * (1.0 - dist / 2.0))
            sp = interface.field_to_ned(
                offset_x * 0.2,   # 小幅微调
                offset_y * 0.2,
                max(alt - rate, 0.3)
            )
            interface.update_setpoint(sp)
        else:
            # 无视觉 → 纯垂直慢速下降
            sp = interface.field_to_ned(0.0, 0.0, max(alt - 0.1, 0.3))
            interface.update_setpoint(sp)

        if alt <= 0.5:
            await interface.land()
            self.is_completed = True
            return True, None

        return False, None
```

## 六、asyncio 并发模型

整个程序跑在一个事件循环中，任务分工：

```
asyncio Event Loop
├── Task 1: _heartbeat_loop()       20Hz  持续发送 setpoint（雷打不动）
├── Task 2: _telemetry_watcher()    异步   更新健康状态快照
├── Task 3: _battery_watcher()      异步   监控电池
├── Task 4: main_fsm.run()           主任务  状态机循环（调用各状态 execute）
├── Task 5: vision_capture_loop()    30Hz  摄像头抓帧（丢线程池，不阻塞）
└── Task 6: logger_task()           10Hz  写入黑匣子日志
```

关键原则：
- 心跳 task 独立于主逻辑，确保 PX4 不会退出 Offboard
- 视觉处理（YOLO 推理）通过 `run_in_executor` 丢到线程池，不阻塞事件循环
- `latest_cmd` 等共享变量读写在单线程 asyncio 中天然线程安全，无需加锁

```python
# main_fsm.run() 外部的并发 task 示例

async def vision_capture_loop(interface: PX4Interface):
    """独立 task: 持续抓帧 + 更新视觉结果"""
    cap = cv2.VideoCapture(0)
    loop = asyncio.get_running_loop()
    executor = ThreadPoolExecutor(max_workers=2)

    while True:
        # 抓帧丢线程池
        ret, frame = await loop.run_in_executor(executor, cap.read)
        if ret:
            # 更新全局帧缓存（供各状态使用）
            global_latest_frame = frame
        await asyncio.sleep(0.033)  # ~30Hz
```

## 十、仿真实测问题记录

以下为在 Gazebo Harmonic + PX4 v1.16.1 SITL 环境下测试发现的问题及解决方案。

### 问题 1：MAVLink 端口变更

**现象**：程序使用默认 `udp://:14540` 无法连接 PX4。

**原因**：Gazebo SITL 的 MAVLink offboard 端口分配与 jMAVSim 不同。PX4 在 Gazebo 下**监听端口 14580**（非 14540），并将遥测发送至端口 14540。

```
px4-rc.mavlink:
  udp_offboard_port_local = 14580    # PX4 监听
  udp_offboard_port_remote = 14540   # PX4 发送
```

MAVSDK 的 `udp://:14540` 尝试绑定并直接发送到 14540，PX4 不在该端口监听，连接失败。

**解决方案**：将默认连接地址改为 `udp://0.0.0.0:14540`，MAVSDK 绑定 14540 接收 PX4 下发数据后，自动获知 PX4 监听 14580 并回复。

**涉及文件**：`run_mission.py`（`--address` 默认值）、`interface.py`（`__init__` 参数默认值）

---

### 问题 2：`str(mode)` 永远不等于 `"OFFBOARD"`

**现象**：全局健康检查始终失败，任务在解锁后立即触发 `[EMERGENCY] Global health check failed`，无人机被解除武装。

**原因**：代码使用 `str(mode) == "OFFBOARD"` 判断飞行模式。MAVSDK v3.15.3 的 `flight_mode()` 返回 `FlightMode` 枚举对象，其 `str()` 输出形如 `"FlightMode.OFFBOARD"` 而非 `"OFFBOARD"`。

**解决方案**：改为 `mode.name == "OFFBOARD"`，兼容使用 `hasattr(mode, "name")` 判断。

**涉及文件**：`interface.py:global_guard_check()` → `mode.name`

---

### 问题 3：`gps_fix_type` 永不更新导致健康检查失败

**现象**：修复问题 2 后健康检查仍失败。`is_healthy` 要求 `gps_fix_type >= 3`，但该字段始终为默认值 0。

**原因**：`HealthStatus.gps_fix_type` 默认值为 0。原设计中 `_telemetry_watcher` 通过 `async for` 持续读取 `telemetry.health()` 来更新健康字段，但 `telemetry.health()` 对象**不包含 `gps_fix_type` 字段**。代码中从未从 `telemetry.gps_info()` 读取 GPS 定位类型。

**解决方案**：
1. 将 `gps_fix_type` 默认值改为 3（SITL 中恒为 3D Fix）
2. 在 `global_guard_check()` 轮询周期中新增 `telemetry.gps_info()` 读取：
   ```python
   async for gps in self.drone.telemetry.gps_info():
       self.health.gps_fix_type = gps.fix_type.value
       break
   ```

**涉及文件**：`interface.py:HealthStatus.gps_fix_type` 默认值、`interface.py:global_guard_check()`

---

### 问题 4：`FixType` 枚举不支持 `int()` 和 `>=` 比较

**现象**：程序崩溃：
```
TypeError: int() argument must be a string, a bytes-like object or a real number, not 'FixType'
TypeError: '>=' not supported between instances of 'FixType' and 'int'
```

**原因**：MAVSDK 的 `gps_info().fix_type` 返回的是 protobuf `FixType` 枚举，不能直接 `int()` 转换，也不能与 `int` 做 `>=` 比较。

**解决方案**：使用 `.value` 属性获取枚举的整数值。`FixType.value` 返回 0（NO_GPS）到 6（RTK_FIXED）的整数。

```python
self.health.gps_fix_type = gps.fix_type.value  # ✅，不是 int(gps.fix_type) ❌
```

**涉及文件**：`interface.py:global_guard_check()`

---

### 问题 5：`_telemetry_watcher` 中 `async for` 永久阻塞

**现象**：`_status_text_watcher`（estimator 异常监控）从未被执行。

**原因**：原代码将两个 `async for` 写在同一函数中顺序执行：
```python
async def _telemetry_watcher(self):
    async for health in self.drone.telemetry.health():  # ← 永久阻塞于此
        ...
    async for status_text in self.drone.telemetry.status_text():  # ← 永远不到
        ...
```
MAVSDK 的 `async for` 是无限流式订阅，第一个循环永不退出，第二个循环永远不会执行。

**解决方案**：将每个 `async for` 放入独立的 `asyncio.create_task()`，确保它们并行运行。

**涉及文件**：`interface.py:connect_and_setup()` — 独立 task 注册

---

### 问题 6：`global_guard_check()` 高频创建 gRPC 订阅导致回调队列溢出

**现象**：控制台打印大量 `User callback queue slow (queue size: 10..30+)` 后程序卡死。

**原因**：`global_guard_check()` 每 50ms（FSM_LOOP_HZ=20）调用一次，每次调用创建 **3 个** `async for` 订阅（`connection_state`、`armed`、`flight_mode`），即每秒 60 个 gRPC 流的创建/销毁。叠加后台 watcher 的持久流，MAVSDK 内部的 gRPC 回调处理线程无法及时消化。

MAVSDK Python 的 `async for` 每次调用都会：
1. 向 MAVSDK C++ 后端注册新 gRPC 订阅
2. 后端推送数据到 Python 回调队列
3. 高频创建/销毁导致队列积压 → 延迟放大器 → 更多积压

**解决方案**：
1. **移除所有后台持久 watcher**（`_state_watcher`、`_gps_watcher`、`_battery_watcher` 等），消除持久 gRPC 流
2. **`global_guard_check()` 降频至 2 Hz** — 使用 `time.monotonic()` 节流，两次检查之间返回缓存结果
3. **将所有遥测读取集中到一次降频轮询中** — 在 0.5s 间隔内顺序执行 5 个带 `break` 的点查询（`connection_state`、`armed`、`health`、`gps_info`、`battery`、`position`）
4. **`get_altitude()` 改为返回缓存值** — 不再创建新的 gRPC 订阅，直接读 `health.altitude_m`（在 `global_guard_check` 中更新）

**节流后的 gRPC 调用总量**：~10 次/秒（2Hz × 5 个查询），约为原来的 1/6。

**涉及文件**：`interface.py:global_guard_check()`、`interface.py:get_altitude()`、`interface.py:connect_and_setup()`

---

### 问题 7：首次 `global_guard_check()` 读取竞态条件

**现象**：修复问题 6 后，Arm + Offboard 成功但首次健康检查仍失败。

**原因**：`connect_and_setup()` 和 `arm_and_offboard()` 成功完成后，`is_connected`、`is_armed`、`is_global_position_ok` 等字段的值仅保存在运行时的临时变量中，未回写到 `self.health` 缓存。`global_guard_check()` 首次读取时，轮询的结果可能覆盖之前的设置，或者节流逻辑跳过了首次读取（`_last_guard_read` 初始化为 0.0，`now - 0.0 > 0.5` 在极端情况可能为 False）。

**解决方案**：
1. 关键操作成功后**同步更新缓存**：
   - `connect_and_setup()` → 显式设置 `is_connected`、`is_global_position_ok`、`is_home_position_ok`
   - `arm_and_offboard()` → 显式设置 `is_armed`、`is_offboard`
2. 确保节流逻辑对首次调用有效（`_last_guard_read` 初始为 0.0，`now - 0.0 > 0.5` 对于任何真实时间戳始终为 True）

**涉及文件**：`interface.py:connect_and_setup()`、`interface.py:arm_and_offboard()`

---

### 问题 8：`COMMAND_DENIED` 异常导致任务崩溃

**现象**：健康检查失败触发 `disarm()` 时 PX4 返回 `COMMAND_DENIED`，异常未捕获导致程序崩溃。

**原因**：健康检查失败时，无人机可能已不在 Offboard/Armed 状态（或正在过渡），`offboard.stop()` 和 `action.disarm()` 在该状态下被 PX4 拒绝。原代码未对该异常做 try/except 保护。

**解决方案**：在 `disarm()` 方法中对 `offboard.stop()` 和 `action.disarm()` 分别包 `try/except`，忽略 `COMMAND_DENIED` 等拒绝异常（因为目标状态已达到，拒接也安全）。

**涉及文件**：`interface.py:disarm()`

---

### 问题 9（非致命）：Gazebo 相机插件缺失

**现象**：PX4 控制台输出：
```
[Err] [SystemLoader.cc:92] Failed to load system plugin [libGstCameraSystem.so]
```

**原因**：Gazebo 的 GStreamer 相机模拟插件未安装。不影响飞行控制，但仿真中的相机传感器不可用（影响视觉状态调试）。

**解决方案**：安装 `libgz-sim8-gst-camera-system` 包（如仓库有提供），或使用 Gazebo 内置的简单相机传感器替代。视觉状态调试可先用真实摄像头或预先录制的图像替代。

---

### 问题 10：VMware 虚拟机 Gazebo GUI 黑屏

**现象**：Gazebo GUI 窗口打开但无任何场景/模型显示，`gz model --list` 确认模型已生成。

**原因**：Gazebo Harmonic 默认使用 Ogre2 渲染引擎，需要 OpenGL 3.3+ 及较高的 GPU 能力。VMware SVGA II 虚拟显卡不支持 Ogre2 所需特性。

**解决方案**：启动时设置环境变量切换到 Ogre1 兼容模式：
```bash
PX4_GZ_SIM_RENDER_ENGINE=ogre make px4_sitl gz_x500
```
Ogre1 使用传统 OpenGL 路径，对虚拟 GPU 兼容性更好。
