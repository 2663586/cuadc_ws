# 状态机设计

> 栈式抢占状态机 + offboard 心跳连续性的设计方案。

---

## 一、目标

任务过程中可能出现「需要临时切换状态，完成后回到原位置继续」的场景：

- 一边执行航线搜索，一边检测到目标 → 切入投放状态 → 投放完毕 → 回到航线继续搜索
- 巡航途中电池低于阈值 → 切入 RTL → 不回到原状态（任务终止）
- 投放过程中视觉丢失 → 切入重搜索状态 → 找回后继续投放

核心需求：**抢占、挂起、恢复**。

---

## 二、当前架构（线性队列）

```
main_fsm.py
    mission_queue = [Takeoff, Hover, Land]
    逐一遍历，不可中断，不可回退
```

适合简单流程（起飞→悬停→降落），不支持中途切入。

---

## 三、目标架构（栈式状态机）

### 3.1 数据结构

```
状态栈（list，尾端为栈顶）

┌──────────┐
│  Search  │ ← stack[-1] 当前执行
├──────────┤
│  Transit │   挂起
├──────────┤
│  Hover   │   挂起
├──────────┤
│ Takeoff  │   挂起
└──────────┘
```

- **push**：新状态压入栈顶，抢占当前状态
- **pop**：栈顶状态完成/失败，弹出，恢复下一层

### 3.2 生命周期方法

`BaseState` 在现有 `enter` / `execute` / `exit` 基础上增加两个方法：

| 方法 | 调用时机 | 职责 |
|------|---------|------|
| `enter()` | 状态首次成为栈顶 | 初始化、发 setpoint |
| `execute()` | FSM 每周期调用 | 核心逻辑，返回结果 |
| `exit()` | 状态被弹出栈 | 清理、收尾 |
| **`suspend()`** | **被新状态抢占时** | **保存断点** |
| **`resume()`** | **上层状态弹出后恢复** | **从断点继续** |

### 3.3 execute 返回值

```python
@dataclass
class ExecutionResult:
    done: bool = False               # True = 本状态完成，弹出
    interrupt: Optional[BaseState] = None  # 非空 = 抢占此状态
    error: Optional[str] = None      # 错误信息
```

四种情况：

| 返回值 | 含义 | FSM 动作 |
|--------|------|---------|
| `done=True` | 状态正常完成 | pop → 恢复下层 |
| `interrupt=<State>` | 检测到需要抢占 | suspend 当前 → push 新状态 |
| `interrupt=None, done=False` | 继续执行 | 下一周期再调 execute |
| `error="..."` | 状态异常 | 触发 _handle_state_error |

## 四、FSM 主循环

```python
class MissionFSM:
    def __init__(self, interface):
        self._stack: list[BaseState] = []

    def build_mission(self):
        self._stack = [
            HoverState(hover_time=1.0),
            TransitState(...),
            SearchState(timeout_s=120),
        ]

    async def run(self):
        self.build_mission()
        await self.interface.connect_and_setup()
        await self.interface.arm()
        await self.interface.takeoff(CRUISE_ALTITUDE_M)
        await self.interface.switch_to_offboard()

        while self._stack:
            state = self._stack[-1]  # 栈顶

            # ---- 首次进入 ----
            if not state._entered:
                await state.enter(self.interface)
                state._entered = True

            # ---- 全局健康检查 ----
            if not await self.interface.global_guard_check():
                await self._handle_unhealthy("状态执行中健康检查失败")
                return

            # ---- 执行 ----
            try:
                done, interrupt, error = await state.execute(self.interface)
            except Exception as e:
                await self._handle_state_error(state, e)
                break

            if error:
                await self._handle_state_error(state, RuntimeError(error))
                break

            if interrupt:
                # ---- 抢占：挂起当前，压入新状态 ----
                await state.suspend(self.interface)
                self._stack.append(interrupt)
                continue

            if done:
                # ---- 完成：弹出，恢复下层 ----
                await state.exit(self.interface)
                self._stack.pop()
                if self._stack:
                    await self._stack[-1].resume(self.interface)
                continue

            await asyncio.sleep(1.0 / FSM_LOOP_HZ)

        await self._ensure_disarmed()
```

### 4.1 为什么用栈而不是队列

| | 队列 | 栈 |
|---|---|---|
| 抢占 | 需要重新构建队列 | 直接 push |
| 恢复 | 无从恢复，需要重新搜索 | pop 后 resume，从断点继续 |
| 嵌套深度 | 不支持 | 支持多层（实际 2-3 层） |
| 复杂度 | 简单 | 略高 |

## 五、抢占示例：航线搜索 → 投放 → 回到搜索

### 5.1 SearchState

```python
class SearchState(BaseState):
    def __init__(self, timeout_s=120):
        super().__init__("Search", timeout_s)
        self._scan_line = 0       # 当前扫描行
        self._progress = 0.0      # 沿扫描行的进度

    async def execute(self, interface):
        # 沿扫描航线移动
        target = self._scan_once(interface)
        if target:
            self._checkpoint = {"line": self._scan_line,
                                "progress": self._progress}
            drop_state = DropState(bottle=target.bottle_index,
                                   position=target.ned_position)
            return ExecutionResult(interrupt=drop_state)
        return ExecutionResult()

    async def suspend(self, interface):
        # 保存断点（已在 execute 中完成）
        pass

    async def resume(self, interface):
        # 从断点恢复扫描
        sp = self._waypoint_at(self._checkpoint["line"],
                               self._checkpoint["progress"])
        interface.update_setpoint(sp)
```

### 5.2 DropState（示例，后续实现）

```python
class DropState(BaseState):
    def __init__(self, bottle, position, timeout_s=30):
        super().__init__("Drop", timeout_s)
        self.bottle = bottle
        self.target = position

    async def enter(self, interface):
        interface.update_setpoint(self.target)
        print(f"[投放] 对准 {self.bottle} 号瓶")

    async def execute(self, interface):
        if self.is_aligned():
            await interface.set_actuator(1, 1.0)   # 开舵机
            await asyncio.sleep(0.5)
            await interface.set_actuator(1, 0.0)   # 关舵机
            return ExecutionResult(done=True)
        return ExecutionResult()
```

### 5.3 时序

```
时间 ──────────────────────────────────────────────────►

栈: [Takeoff, Hover, Transit, Search]
                              │
                         Search.execute()
                         检测到目标
                              │
                              ▼ suspend Search
栈: [Takeoff, Hover, Transit, Search, Drop]
                              │
                         Drop.enter()  ← 设 setpoint 到对准位置
                         Drop.execute()
                         投放完成
                              │
                              ▼ pop Drop
栈: [Takeoff, Hover, Transit, Search]
                              │
                         Search.resume()  ← 从断点继续扫描
```

**关键**：整个过程中心跳循环始终以 20 Hz 发送当前 setpoint。状态切换时 setpoint 的更新是瞬时的——`update_setpoint()` 只改内存中的一个变量，心跳在下一个周期（最多 50ms 后）就发新值。

## 六、抢占的两种模式

### 模式 A：可恢复抢占（suspend/resume）

```
Search ──检测目标──► Search.suspend() → Drop.push()
Drop.pop() → Search.resume()  ← 从断点继续
```

适用场景：搜索→投放、巡航→避障

### 模式 B：不可恢复抢占（替换栈）

```
任何状态 ──电池低──► 清空栈 → RTL.push()
```

适用场景：紧急返航、致命错误。不保存断点，栈中所有状态被丢弃。

```python
async def _handle_unhealthy(self, reason: str):
    """紧急情况：清空栈，触发 RTL。"""
    self._stack.clear()          # 丢弃所有挂起状态
    await self.interface.drone.action.return_to_launch()
```

## 七、offboard 心跳与状态切换的配合

这是整个设计中最重要的机制保证：

```
┌──────────────────────────────────────────────────┐
│                _heartbeat_loop                    │
│  while True:                                     │
│      set_position_ned(_last_setpoint)  ← 20 Hz   │
│      sleep(50ms)                                 │
└──────────────────────────────────────────────────┘
                        ▲
                        │ 只读
                   ┌────┴────┐
                   │ _last_  │
                   │ setpoint│  ← 任何状态通过 update_setpoint() 写入
                   └─────────┘
                        ▲
        ┌───────────────┼───────────────┐
        │               │               │
   Search.update    Drop.update    Transit.update
   _setpoint()      _setpoint()    _setpoint()
```

- 状态只负责「声明意图」（目标在哪）
- 心跳负责「持续传达」（每 50ms 告诉飞控）
- 两者解耦，状态切换不需要通知心跳

PX4 端的行为：
- 心跳不断发同一个位置 → PX4 位置控制器持续追踪
- 状态切换，心跳下一个周期发新位置 → PX4 平滑过渡到新目标
- 只要心跳不中断超过 500ms，PX4 不会退出 offboard

## 八、安全边界

| 风险              | 缓解措施                                                 |
| --------------- | ---------------------------------------------------- |
| 栈无限增长           | 限制最大深度（如 5 层）；`_handle_unhealthy` 清空栈                |
| suspend 时断点保存失败 | checkpoint 在 execute 返回 interrupt 前保存，不在 suspend 中保存 |
| resume 时状态已变化   | resume 中先读当前遥测，再计算新 setpoint                         |
| 抢占链过长导致超时       | 每层状态独立计时；全局超时检查在 global_guard_check 中                |
| 多个状态同时想抢占       | execute 返回值只有一个 interrupt；FSM 单线程，不存在竞态              |

## 九、与当前代码的对应

| 当前 | 栈式改进后 |
|------|-----------|
| `mission_queue: list` | `_stack: list` |
| `while state_index < len(...)` | `while self._stack` |
| `done, _ = await state.execute()` | `done, interrupt, error = await state.execute()` |
| 完成 → `state_index += 1` | 完成 → `pop()` + `resume()` |
| 不支持中断 | `interrupt` → `suspend()` + `push()` |
| `_handle_unhealthy` 不清理队列 | `_handle_unhealthy` 清空栈 |
