## 全局健康看门狗 (Global Guard)

 在主循环中，在执行任何状态前，先运行一次健康检查。
 
 **应用场景**：代码中需实时监控 estimator_status 。若检测到 RTK 定位精度方差突增，无论当前处于什么状态（哪怕正在对准水桶），看门狗强制拦截并把状态机切换为悬停（HOVER）并报警，等待人工接管

## Offboard心跳维持机制 (Heartbeat)：

PX4 的 Offboard 模式有一个严格的底层安全逻辑：在切换入 Offboard 模式之前，必须已经持续发送设定点（位置或速度）至少 1-2 秒，并且在整个任务期间发送频率不能低于 2Hz 。如果状态机在计算视觉误差时卡顿了 0.5 秒没发指令，飞机将直接退出 Offboard 并触发保护（如就地降落或返航）。

**应对**​：在 mavros_interface.py 中开一个独立的定时器线程，如果主逻辑没有下发新指令，接口层自动重发上一条指令，或者发送原位悬停指令。

## 状态内超时机制 (Timeout)：

每个状态的 enter() 中必须记录时间戳。

**应用场景**：由于无人机机动可能导致桶飞出视野，系统需具备“记忆能力”，在丢失目标时向最后已知方向慢速飞行搜索 。如果在这个搜索状态超过 3 秒，就必须强制切换状态（例如拉高高度重新搜索，或者放弃该目标直接飞往第二任务区 ），绝不能死等死循环。

```
#规定了每个状态必须拥有 enter, execute, exit 三个标准生命周期函数。
class BaseState:
    def __init__(self, name):
        self.name = name          # 状态名称，用于日志打印
        self.interface = None     # 预留接口，用于调用底层的无人机控制函数

    def enter(self):
        """进入该状态时执行一次"""
        pass

    def execute(self):
        """主循环中以 20Hz 疯狂执行，返回 True 表示任务完成，返回 False 表示继续"""
        return False

    def exit(self):
        """退出该状态时执行一次"""
        pass
```

1. 三个生命周期。
